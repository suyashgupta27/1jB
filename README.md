# 1jB

> **A proposal introducing the jB quantity**  
> **1 jB = 10⁻¹³⋅⁵**

---

## Overview

The **jB** is a proposed **fun, dimensionless quantity** defined as

**1 jB = 10⁻¹³⋅⁵ ≈ 3.16227766017 × 10⁻¹⁴**

It is simply a memorable way to represent the value **10⁻¹³⋅⁵** whenever it appears in mathematics, programming, scientific computations, or just for fun.

---

## Definition

By definition,

```text
1 jB = 10⁻¹³⋅⁵
```

Approximate decimal value:

```text
1 jB = 0.000000000000031622776601683793
```

Scientific notation:

```text
1 jB = 3.16227766017 × 10⁻¹⁴
```

## Example Usage

Instead of writing

```text

```

```text

```

Likewise,

```text

```

## Why?

There is no official scientific motivation behind **jB**—it is simply a **fun quantity** introduced to give a memorable name to the number **10⁻¹³⋅⁵**.

Sometimes numbers become easier to remember when they have a name. This repository is a light-hearted attempt to do exactly that.
